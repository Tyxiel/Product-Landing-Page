# Droid Watches - Landing Page

Uma landing page responsiva e visualmente atraente para a marca "Droid Watches", criada para destacar as funcionalidades de smartwatches. Este projeto é um dos cinco necessários para a certificação de Design Responsivo da Web do freeCodeCamp.

## Sobre o Projeto

Esta é uma landing page desenvolvida para apresentar a linha de smartwatches "Droid Watches". O design foca em ser moderno e informativo, utilizando recursos como um vídeo de fundo, seções de características detalhadas e um formulário de contato simulado. O projeto demonstra habilidades em HTML semântico, CSS para estilização e layout responsivo, e JavaScript para interatividade e navegação suave.

## Funcionalidades

* Design responsivo que se adapta a diferentes tamanhos de tela.
* Barra de navegação fixa com links para diferentes seções da página.
* Rolagem suave ao clicar nos links de navegação.
* Destaque do link ativo na barra de navegação conforme a rolagem.
* Seção de "Features" destacando os benefícios do produto.
* Incorporação de vídeo promocional.
* Formulário para submissão de e-mail (simulado).
* Efeitos de hover interativos nos ícones da navegação.

## Tecnologias Utilizadas

* **HTML5**: Estrutura semântica da landing page.
* **CSS3**: Estilização completa, layout flexbox/grid, e design responsivo.
* **JavaScript (ES6+)**: Para navegação suave, atualização de links ativos e interações de UI.
* **Boxicons**: Para os ícones utilizados na interface. (https://boxicons.com/)
